Hardware integration

実機との接続 — Tecan Fluent 自律実験系での能動学習

合成ベンチマークで検証した OFML の枠組みを、実機の自律実験系に接続した予備デモ。液体ハンドラ Tecan Fluent・サーモサイクラー ODTC・プレートリーダー Magellan を SiLA / 遠隔実行で駆動し、色素混合（ColorMix）タスクで「プロトコルを操作の合成として扱い、終端の測定値のみから能動学習する」という論文の主張をそのまま実機で回した。プロトコル＝混合レシピ、操作＝分注・混合、終端の測定値＝吸光度である。

ColorMix タスク ＝ 実機版 OFML

プロトコルを操作の合成として実機化

ColorMix は、水・Red・Yellow・Blue の色素を各 well へ分注・混合し、生成した色（吸光度）を予測・最適化するタスクである。これは論文の抽象を実機へ写像したものだ：

※ 操作型 Red / Yellow / Blue＝色素分注、Mix＝混合、Read＝終端の吸光度測定。同じ操作型（例：Red 分注）が異なるレシピで再利用される＝重み共有による転移の実機版。中間状態（混合途中の色）は観測せず、終端の測定値のみを得る。

終端の測定値＝吸光度（3 波長）

各 well の観測は Magellan による 430 / 520 / 630 nm の吸光度（blank 補正済み）。中間の分注量や混合過程そのものは教師信号にせず、最終ウェルの測定値のみから代理モデルを学習する（＝論文の terminal-only 設定）。

ハードウェア構成と遠隔実行

装置スタック

Tecan Fluent（8 チャネル LiHa 液体ハンドラ：色素・水の分注、tip 管理）＋ ODTC（Inheco サーモサイクラー：温調が必要な系）＋ Magellan（プレートリーダー：吸光度測定）。FluentControl の監査ログ（AuditTrail）と SiLA の進捗（RunModeRunFinished / Progress 100）で各 run の成否を機械可読に確認する。

安全側の乾式再設計

8 チャネル同時 Aspirate が Active Stop になった知見から、source runner は physical channel 1 のみ・1 回の色素 Aspirate を 140 µL 以下に制限する乾式（dry-run 検証付き）設計へ再構成。validate_colormix_source_plan.py が全プレートで PASS し、実機でも検証済み。実機コマンドを送る前に必ず計画検証を通す。

source キャンペーンと能動学習

取得済みデータ

source campaign：3 枚の source plate から合計 264 件の source observations を取得（各プレート 88 well、水 8 blank ＋ 3 色）。生 ASC は Windows/Mac 間で SHA-256 一致・shape (3, 8, 12)・全値 finite を確認。
能動学習：凍結した pre-active baseline（264 source obs, 0 active）から開始し、iterations 1–11 で A2–A12 の wet observation 11 件を実機取得した。

評価の分離（prequential）

各 iteration で 3 種類を厳密に分けて報告する：(1) 新規 well の取得前予測 vs 実測＝one-step prequential test（唯一の unbiased test）、(2) 再学習後の同一 well 予測＝training-point assimilation 診断（test ではない）、(3) 既開封 16-well 固定パネルの取得前後差＝regression monitoring（unbiased test ではない）。取得前 baseline の Spearman ρ は 430/520/630 nm で 0.97 / 0.94 / 0.87。

論文の主張との対応

この実機デモは論文の 3 点をそのまま体現する：終端の測定値のみから学習（terminal-only）、同一操作型の重み共有による転移（主張 1）、次の well を選んで能動的に測定し誤差を下げる閉ループ（主張 2）。合成ベンチマーク（Experiments）で確立した挙動を、実試薬・実装置で確認する第一歩である。

再現性・来歴

すべての成果物に SHA-256 を付し、pre-active baseline を 読み取り専用（-r--r--r--）で dgx1 と Mac の両方に保存。36 ファイルの内部チェックが両環境で PASS。生 ASC → blank 補正 → CSV までを検証済みのパイプラインで再現でき、実機コマンドは監査ログと SiLA 進捗で照合する。実装の詳細は内部リポジトリ tecan_fluent_demo（Tecan Fluent 遠隔実行手順・ColorMix runner・Magellan 取り込み）に集約している。

位置づけ（限界）

本ページは予備デモであり、論文の主結果ではない。色素混合は吸光度が加法的に近く識別しやすい良性タスクで、酵素反応など非線形・多段の系はこれから。実機の失敗モード（チャネル停止・tip 消費・温調待ち）は乾式検証と単一チャネル方式で回避しているが、スループットは限定的である。目的は「OFML の terminal-only ＋ 能動学習の枠組みが実機ループとして回ること」を示すことにある。
