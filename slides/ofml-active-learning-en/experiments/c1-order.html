Claim 1 · composition aids transfer (order identification)

Fig. 3b — forward transfer via order identification (non-commutativity)

The core of Claim 1. We measure whether a non-commutative operation sequence (order) can be forward-transferred from the source to a held-out order, using macro NRMSE on the held-out order. The linear composition OFML-linear identifies each operation's matrix from the source and exactly reconstructs the held-out order as an ordering of matrix products (macro NRMSE ≈0.017). The composition net OFML-Ens, which explicitly sees the training order, is small on the training reference but collapses on held-out orders, and Shared-Ens, which sees only the operation count, cannot distinguish same-count / different-order and fails on every order. This is a direct verification of the main theorem's rank condition \(\ker\Phi\subseteq\ker\Psi\) (Proposition 4(i)) itself.

Goal (summary of the claim)

For non-commutative operation composition, we directly test Claim 1 — "if the source spans the order directions (i.e., if it is identifiable), forward transfer to a held-out order is possible" — via macro NRMSE on the held-out order. The linear composition OFML-linear identifies each operation's \(2\times2\) matrix from the source and exactly reconstructs a held-out order as an ordering of matrix products (NRMSE ≤0.026 for all 4 orders, macro 0.017). The composition net OFML-Ens, which explicitly sees the training order, is small on the training reference A B C M O (0.076) but collapses on held-out orders (macro 1.256), and the order-blind Shared-Ens, which sees only the operation count, cannot distinguish same-count / different-order and fails on every order (macro 2.169). We isolate that the key to transfer is not "composition per se" but "composition with identifiability".

Setup

A composed affine-linear family (non-commutative operations \(\{A,B,C\}\) + terminal \(M\) · linear readout \(O\)). The source is 12 protocols that span the order: 3 single-operation protocols (A M O, B M O, C M O), 6 two-operation pairs in both orders (A B M O/B A M O, A C M O/C A M O, B C M O/C B M O), and 3 full permutations that are not held out (A B C M O, B C A M O, C A B M O). These excite each operation matrix and the principal non-commutative directions, and satisfy \(\ker\Phi\subseteq\ker\Psi\) at the true \(\theta\). The target is 1 training reference A B C M O and 3 held-out protocols A C B M O·B A C M O·C B A M O (the remaining 3 permutations that never appear in the source; their count is identical to the training reference and only the order differs). Each protocol is learned with per_proto=40 points and evaluated on n_test=120 points (noise-free · ground truth). All 3 models see the same source/target evidence (a pure structural comparison). With the 12 bench seeds as the primary statistical unit, all metrics are macro NRMSE. Observation noise \(\sigma=0.02\).

※ The 3 held-out orders have a count that is exactly identical to the training reference and differ only in order (a design that exposes order-blind aliasing). OFML-linear is deterministic linear identification + composition, so seed variation is only at the level of numerical / observation noise, whereas OFML-Ens / Shared-Ens are seed-only 5-member deep ensembles (capacity-matched hidden_dim=32). We do not use raw RMSE; everything is unified as NRMSE normalized by each target's own scale.

Detailed setup (seed taxonomy · procedure · QC)
Seed taxonomy. The bench_seed (12 of them) is the primary statistical unit and redraws the true affine-linear family itself (the operation matrices + readout). Derived streams are separated: task=bench_seed, pool=bench_seed×7+1, noise=bench_seed×7+2, model=bench_seed (pairing across models by task = paired comparison). Sobol uses sob=bench_seed×100003 + fixed offset (test +11 / grid +301). Because OFML-linear uses closed-form identification, its seed dependence is only via observation noise.

Procedure. All models see the same 12 source rows and the same target evidence (40 points of the training reference A B C M O). OFML-linear identifies each operation matrix from the source by least squares and evaluates by composing the target order as a matrix product (held-out orders are zero-shot: no target evidence required). OFML-Ens / Shared-Ens learn from source + training reference and predict held-out orders.

QC / leakage control. The test is noise-free (no train-on-test), and the 3 held-out orders appear in neither the source nor the training reference (no order leakage). The count is fixed identical across the 4 orders, eliminating confounds other than order (operation set · depth). All records have status=ok.

How to read it. Only the NRMSE difference on held-out orders measures "whether the order (non-commutativity) could be identified". By the design of identical count · differing only in order, the failure of Shared-Ens gives the fundamental lower bound (the order-blind floor).
Result

OFML-linear is best on all 4 orders (the minimum for each order). Even on the 3 held-out orders it stays at NRMSE ≤0.026, reconstructing as a matrix product an order it has never seen in training = it identifies the order (non-commutativity). OFML-Ens is small on the training reference A B C M O (0.076) but collapses to 0.635–2.691 on held-out orders (macro 1.256) = it cannot extrapolate the order. Shared-Ens cannot distinguish the 4 orders with identical count and is high even on the training reference (1.417), with macro 2.169 (the order-blind floor).

Discussion — how it supports the claim

Success or failure on held-out orders demarcates the core of Claim 1. OFML-linear transfers non-commutative composition zero-shot when the source spans the order directions (\(\ker\Phi\subseteq\ker\Psi\)) = Claim 1. The collapse of OFML-Ens shows that, even with the same composition structure, a fit that does not guarantee identifiability does not extrapolate to unobserved orders (composition is not a sufficient condition for transfer; identifiability is the key). Shared-Ens erases the order in principle because it uses a count descriptor, so it cannot distinguish same-count / different-order = the identification limit of terminal-only / order-blind = Claim 1. By the design of identical count · differing only in order, this gap purely measures only "whether the order (non-commutativity) could be identified".

For a direct audit of identifiability (the \(\Phi/\Psi\) ranks of the true \(\theta\)), see the Φ/Ψ audit; for the linear s0 parity, see Fig. 3a; for count aliasing, see Fig. 3c; and for the positioning under the cost-indexed view, see Fig. 2.

※ Limitations: the near-zero error of OFML-linear is a result on a composed family where linear identification is exactly effective, and the residual is due to numerical / observation noise \(\sigma=0.02\). The held-out orders are restricted to matching count · differing only in order (confounds other than order are eliminated). The collapse values of OFML-Ens have large seed variance (especially A C B M O), and the point estimates are 12-seed averages. The figure's vertical axis is clipped to 0–3 (the OFML-linear bars are drawn with a minimum height of 3px for visibility; the labels and table are authoritative for the true values).

Correspondence with theory

This experiment verifies the main theorem's rank condition directly. When the source spans the order directions and \(\ker\Phi\subseteq\ker\Psi\) holds, the linear composition transfers exactly to a held-out order (the rank condition itself of Proposition 4(i); equivalently \(\mathrm{row}(\Psi)\subseteq\mathrm{row}(\Phi)\), with the condition number \(K=\sigma_{\max}(\Psi)/\sigma_{\min}^{+}(\Phi)\) governing error amplification). The held-out collapse of OFML-Ens is empirical evidence that a composition fit that does not impose identifiability lies outside the guarantee region of Proposition 4. Even for an order where identification breaks (a permutation the source does not span), terminal-response consistency can be recovered by directly actively observing the target terminal (Theorem 3 · Proposition 5).
