Problem setting

Protocol-Structured Surrogate Modeling Problem with Terminal Measurement

We define the target that OFML solves. We present, point by point in boxes, the protocol structure, the true latent execution, the observation model, the OFML hypothesis class, source→target learning, and the sequential action and cost-indexed objective (the running text is supplementary only). The details of the weight-sharing architecture of the composition are treated in Object-Flow Machine Learning, and the consistency of the terminal-function posterior in Theoretical statement and proofs. The notation is kept consistent with the cost-indexed evaluation of the experiments and with the theory.

3.1 Protocol vocabulary and typed execution graph

Operation vocabulary and protocol set

Let the shared operation vocabulary be \(\Mcal=\{M_1,\ldots,M_m\}\). Each \(M_j\) is an operation type reused across protocols, such as dispensing, mixing, heating, incubation, reaction, or readout preparation. Let the protocol set be \(\Pcal\) and the observed source be \(\Pcal_{\mathrm{src}}\subseteq\Pcal\) (the finite target set to which transfer is directed is defined in 3.4).

Typed directed acyclic graph (DAG) and local input-assembly map

Each protocol \(p\in\Pcal\) is a typed DAG \(p=(V_p,E_p,\tau_p,\iota_p)\). Here \(V_p\) is the node set, \(E_p\) the dependencies, and \(\tau_p:V_p\to\{1,\ldots,m\}\) assigns an operation type to each node. Let the parent set of node \(v\) be \(\Pa_p(v)\) and the external design variable be \(x\in\Xcal_p\). Let the local input space of operation type \(M_j\) be \(\Zcal_j\) and the post-operation latent-state space be \(\Scal_j\); we define once the input-assembly map that assembles the local input of each node as follows:

\[ \iota_{p,v}:\left(\prod_{u\in\Pa_p(v)}\Scal_{\tau_p(u)}\right)\times \Xcal_p \to \Zcal_{\tau_p(v)}. \]
True latent execution (protocol-dependent true map)

We write the true map of each operation type \(M_j\), depending on the protocol in question, as \(F_{j,p}^\dagger:\Zcal_j\to\Scal_j\). Following the topological order of the DAG, the true state is determined from the design variable \(x\) as follows:

\[ z_v^\dagger(x) = \iota_{p,v}\!\left((s_u^\dagger(x))_{u\in\Pa_p(v)},\, x\right),\qquad s_v^\dagger(x) = F_{\tau_p(v),\,p}^\dagger\!\left(z_v^\dagger(x)\right). \]

Note: making the true map protocol-dependent \(F_{j,p}^\dagger\) is intentional. The OFML model shares a single module \(g_{\theta_j}\) across the same operation type (3.3), but whether the truth agrees with that sharing is a condition for transfer to hold, not a premise (C2 in 3.4, Assumption 8). The semantic shift s2 is a failure mode that deliberately breaks this condition.

3.2 Observation model

Observer vocabulary and observable nodes

We separate the measurement devices as an observer vocabulary \(\Qcal=\{Q_1,\ldots,Q_r\}\) distinct from the operation vocabulary. Each observer \(Q_q\) has a true readout map \(h_q^\dagger:\Scal_{j}\to\Ycal_q\) that reads out the latent state of the node at which it is placed. Let the observable-node set of protocol \(p\) be \(\Obs(p)\subseteq V_p\) (the nodes at which observers are placed). We do not assume that arbitrary intermediate node outputs are directly observable; only the outputs of explicitly placed observers can be observed.

Note: separating observers from the operation vocabulary makes future extensions natural—multiple observers, per-observer costs, intermediate measurements, and non-destructive/destructive measurements. In the main setting of this paper, \(\Qcal=\{q_{\mathrm{term}}\}\), \(\Ycal_{q_{\mathrm{term}}}=\R\) (a single terminal scalar observer).

Observation space and noisy observation

Let the observation space be \(\Ycal_p^{\mathrm{obs}}=\prod_{q\in\Obs(p)}\Ycal_q\) and the true observation output be \(\Eval^\dagger(p;x)=\left(h_q^\dagger(s_{v(q)}^\dagger(x))\right)_{q\in\Obs(p)}\) (\(v(q)\) is the node at which observer \(q\) is placed). The observation data is

\[ y_i = \Eval^\dagger(p_i;x_i)+\xi_i,\qquad \E[\xi_i\mid \cdot]=0, \]

where \(\xi_i\) is conditionally unbiased, finite-variance noise on the observation space \(\Ycal_{p_i}^{\mathrm{obs}}\) (Assumption 4 in the theory).

Main setting: terminal-only measurement

In the main setting of this work, each protocol has \(\Obs(p)=\{q_p^{\mathrm{term}}\}\), and the observation data contains only the output of the terminal measurement-device node (a single scalar \(y\)). Even when intermediate stages are observed during learning, they are represented not as the intermediate state itself but as the output of an observer module placed at that position. In this respect, OFML differs from function-network-type Bayesian optimization[bofn], which directly uses intermediate node outputs, and from pKGFN[pKGFN], which presupposes per-node partial evaluation.

3.3 OFML hypothesis class

Shared operation modules and composed predictor

We assign to each operation type \(M_j\) a shared module \(g_{\theta_j}:\Zcal_j\to\Scal_j\) that is learned. The readout head \(h_q\) of observer \(Q_q\) is also a learning target, and we bundle all learnable components (operation modules + observer heads) as \(\theta\in\Theta\) (the terminal readout in the main setting is a fixed scalar measurement, while the intermediate observer head of 1-C is learnable). Composing in the same topological order as the true execution, we define the predictor as

\[ \Eval(p;\theta;x)=\bigl(h_q(s_{v(q)}^{\theta}(x))\bigr)_{q\in\Obs(p)},\quad s_v^{\theta}(x)=g_{\tau_p(v)}\!\bigl(\iota_{p,v}((s_u^{\theta}(x))_{u\in\Pa_p(v)},x);\theta\bigr) \]

Sharing a single parameter \(\theta_j\) across the same operation type is the inductive bias of OFML, and this is what distinguishes it from the unstructured baselines (Shared-Ens / Independent-Ens) that ignore order and count. The details of the composition architecture are in Object-Flow Machine Learning.

Parameter uncertainty and pushforward to the terminal function

Let the uncertainty distribution of the module parameters be \(\Pi_n^\theta\). This does not identify exact posterior, SMC, and deep ensemble with one another; rather, it serves to define the "terminal-function sample" interface that all of them commonly provide. For each target \(p\), via the pushforward \(T_p(\theta)(x)=\Eval(p;\theta;x)\), we obtain the distribution of the terminal function

\[ \Pi_n^{G}=(T_p)_{\#}\,\Pi_n^\theta,\qquad \widehat f_{n,p}(x)=\mu_{n,p}(x)=\E_{\theta\sim\Pi_n^\theta}\!\left[\Eval(p;\theta;x)\right] \]

The prediction is based on this posterior mean \(\mu_{n,p}\), and the active-learning acquisition on the variance of this distribution. \(\Pi_n^{G}\) corresponds to the \(C(\Xcal)\)-valued posterior \(\Law(G\mid\Hcal_n)\) (Lemma 5) whose consistency the theory discusses.

3.4 Source-to-target learning

Separation of source / target data

We split the data into source and target:

\[ \Dcal_n=\Dcal_{\mathrm{src}}\cup\Dcal_{\mathrm{tar},n},\qquad \Dcal_{\mathrm{tar},0}=\emptyset. \]

\(\Dcal_{\mathrm{src}}\) is the source observations fixed before any target cost is counted, and \(\Dcal_{\mathrm{tar},n}\) is the target observations added sequentially. \(n=0\) corresponds to after source pretraining with no target observations (zero-shot transfer), and \(n\ge1\) to target adaptation. The source acquisition cost is treated as a sunk cost common to all models and is not included on the cost axis.

Finite target set and transfer objective

Let the objects of transfer and evaluation be a finite target protocol set \(\Pcal_\star=\{p_1,\ldots,p_K\}\subseteq\Pcal\) (typically \(\Pcal_\star\cap\Pcal_{\mathrm{src}}=\emptyset\)). The true target function of each \(p\in\Pcal_\star\) is \(f_p^\dagger(x)=\Eval^\dagger(p;x)\). The objective is to predict \(\{f_p^\dagger:p\in\Pcal_\star\}\) from the source and (as needed) a small number of target observations.

Note: a single target is the special case \(K=1\). Figure 2 of this paper simultaneously evaluates the two targets \(\Pcal_\star=\{\mathrm{ABO},\mathrm{BAO}\}\) (or \(\{\mathrm{ABCMO},\mathrm{CBAMO}\}\)). Using two targets makes it possible to define the descriptor aliasing floor \(F_{\mathrm{alias}}\) of the order-ignoring Shared-Ens (cost-indexed).

Transfer condition C2 (semantic sharing)

The OFML model always shares \(g_{\theta_j}\), but transfer holds only when the truth agrees with that sharing. We express the shared-semantics condition as

\[ F_{j,p}^\dagger=F_j^\dagger\quad\text{(for relevant }p\text{)} \]

as condition C2. When this breaks (semantic shift s2), zero-shot transfer can fail. For the complete transferability diagnostics C1–C5 see Assumption 8, and for the linear rank condition see Proposition 4.

3.5 Sequential action and cost-indexed objective

History, action, policy

Let the observation history be \(\Hcal_n=\sigma(\Dcal_{\mathrm{src}},\Dcal_{\mathrm{tar},n})\) and the action be \(a_n=(p_n,x_n,q_n)\) (target protocol, design point, observer); the next action is chosen based on the history: \(a_{n+1}=\pi_n(\Hcal_n)\). The candidate set is

\[ \Acal_n\subseteq\bigsqcup_{p\in\Pcal_\star}\{p\}\times\Xcal_p \]

(a finite pool in the experiments, a compact continuous domain in the theory). In the main setting of this paper, \(p_n\in\Pcal_\star\), \(q_n=q_{\mathrm{term}}\), and unit cost \(c(a_n)=1\). This connects to the theory's \(\Pi_n=\Law(G\mid\Hcal_n)\) (Theorem 3).

Cumulative target cost and budget

We write the cumulative target acquisition cost as

\[ B_n=\sum_{i=1}^{n}c(a_i),\qquad \text{under unit cost } B_n=n,\quad B_0=0. \]

\(B_0=0\) is a conditional target cost that does not include the source pretraining cost (the source is a sunk cost common to all models).

Cost-indexed learning objective (unified)

The macro target error at cumulative cost \(b\), normalized by the pooled scale \(s_\star=\sqrt{\sum_{p\in\Pcal_\star} w_p\,\mean((f_p^\dagger-\bar f)^2)}\) (equal weights \(w_p=1/K\)), is defined as

\[ \varepsilon_m(b)=\left(\sum_{p\in\Pcal_\star} w_p\;\E_{x\sim\nu_p}\!\left[\tfrac{\norm{\mu_{n,p}(x)-f_p^\dagger(x)}^2}{s_\star^2}\right]\right)^{1/2},\qquad \bar J(B)=\frac1B\int_0^B\varepsilon_m(b)\,db \]

(\(\nu_p\) = the evaluation distribution over target \(p\), approximated by a finite test set in the experiments; \(\bar J\) uses the trapezoidal rule). The objective of OFML is unified into making \(\varepsilon_m(b)\) small over the entire budget \([0,B]\): \(\varepsilon_m(0)\) measures forward transfer (\(b=0\)), \(\varepsilon_m(b),\,b>0\) measures target adaptation, and we report \(\bar J(B)\) together with the endpoints \(\varepsilon_m(0)/\varepsilon_m(B)\).
