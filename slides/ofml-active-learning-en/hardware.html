Hardware integration

Hardware integration — active learning on a Tecan Fluent autonomous lab

A preliminary demo connecting the OFML framework — validated on synthetic benchmarks — to a real autonomous laboratory. Driving the Tecan Fluent liquid handler, ODTC thermocycler, and Magellan plate reader via SiLA / remote execution, we ran the paper's central claim directly on hardware with a dye-mixing (ColorMix) task: treat a protocol as a composition of operations and actively learn from the terminal measurement only. Protocol = mixing recipe, operation = dispense / mix, terminal measurement = absorbance.

The ColorMix task = OFML on hardware

A protocol as a composition of operations, on hardware

ColorMix first fills each well with 150 µL of water, dispenses Red, Yellow, and Blue dye solutions (operations R/Y/B: 5–40 µL single-color, 4 levels 5/15/25/35 µL for two-/three-color), mixes (M), and reads the terminal observer O (Magellan absorbance at 430/520/630 nm). Protocols are machine-readably defined as compositions of operation symbols (the steps field of experiment.yaml):

The same operation type (e.g. an R dispense) is reused as one shared module across single-, two-, and three-color recipes = the hardware version of transfer by weight sharing. The modules R, Y, B, M learned on single- and two-color sources recombine to predict the unseen three-color target R Y B M O. Intermediate state (the color mid-mixing) is not observed; only the terminal measurement is obtained.

Terminal measurement = absorbance (3 wavelengths)

Each well's observation is the Magellan absorbance at 430 / 520 / 630 nm (blank-corrected). The intermediate dispense volumes and the mixing process itself are not used as supervision; the surrogate learns from the final well's measurement only (= the paper's terminal-only setting).

Hardware stack and remote execution

Instrument stack

Tecan Fluent (8-channel LiHa liquid handler: dye / water dispensing and tip management) + ODTC (Inheco thermocycler: for temperature-controlled systems) + Magellan (plate reader: absorbance measurement). Each run's success is confirmed machine-readably from the FluentControl AuditTrail and the SiLA progress (RunModeRunFinished / Progress 100).

Safety-first dry-run redesign

After 8-channel simultaneous aspirates triggered an Active Stop, the source runner was rebuilt to a dry-run-validated design that uses physical channel 1 only and caps a single dye aspirate at 140 µL. validate_colormix_source_plan.py passes on all plates and was verified on hardware; every plan is validated before any command is sent to the instrument.

Source campaign and active learning

Data collected

Source campaign: 264 source observations collected across 3 source plates (88 wells each: 8 water blanks + 3 colors). Raw ASC files match by SHA-256 across Windows/Mac, with shape (3, 8, 12) and all values finite.
Active learning: starting from a frozen pre-active baseline (264 source obs, 0 active), iterations 1–11 acquired 11 wet observations (A2–A12) on the instrument.

Separated evaluation (prequential)

At each iteration three things are reported and kept strictly separate: (1) pre-acquisition prediction vs measurement of a new well = a one-step prequential test (the only unbiased test); (2) the same-well prediction after retraining = a training-point-assimilation diagnostic (not a test); (3) the before/after difference on a previously-opened 16-well fixed panel = regression monitoring (not an unbiased test). The pre-acquisition baseline Spearman ρ is 0.97 / 0.94 / 0.87 at 430/520/630 nm.

Correspondence with the paper's claims

This hardware demo instantiates the paper's three points directly: learning from the terminal measurement only (terminal-only), transfer by weight sharing — recombining the shared modules learned on single- and two-color sources to predict the unseen three-color target R Y B M O (Claim 1), and a closed loop that actively picks the next well to measure from the three-color candidate grid to drive down error (Claim 2). It is a first step toward confirming, with real reagents and instruments, the behavior established on synthetic benchmarks (Experiments).

Reproducibility & provenance

Every artifact carries a SHA-256, and the pre-active baseline is stored read-only (-r--r--r--) on both the dgx1 and the Mac; internal checks over 36 files pass on both. The pipeline from raw ASC → blank correction → CSV is reproducible under verification, and instrument commands are cross-checked against the audit log and SiLA progress. Implementation details are consolidated in the internal repository tecan_fluent_demo (Tecan Fluent remote-execution guide, ColorMix runner, Magellan ingest).

Positioning (limitations)

This page is a preliminary demo, not a main result of the paper. Dye mixing is a benign task whose absorbance is nearly additive and easy to identify; nonlinear, multi-step systems such as enzyme reactions are future work. Hardware failure modes (channel stops, tip consumption, temperature-control waits) are avoided by dry-run validation and the single-channel scheme, but throughput is limited. The goal is to show that OFML's terminal-only + active-learning framework closes the loop on real hardware.
