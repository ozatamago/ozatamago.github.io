Object-Flow Machine Learning:
Operation-Level Surrogate Modeling for Laboratory Workflows

We treat an experimental protocol not as a single identifier or a flat feature vector, but as a structured input consisting of experimental objects, operation sequences, and measurement instruments. By sharing across protocols the predictive components corresponding to the same operation type, we transfer zero-shot to unseen protocols from a few terminal measurements and correct in closed loop via active learning. This is protocol-structure-preserving surrogate modeling, positioned between a full mechanistic simulator and a single black-box surrogate model. Big picture

Three stages: learn on source, recompose into an unseen protocol, and correct on target

The predictive components of the same operation type (same color) are shared across multiple protocols. This is the sole mechanism of cross-protocol knowledge transfer. We learn shared modules on the source protocols (①), recompose them into an unseen target protocol for zero-shot prediction (②), and perform closed-loop correction via active learning while adding terminal measurements on the target (③).

The real-world object of interest is a protocol. Its abstraction is a composition of shared modules over a typed directed acyclic graph (DAG), assigning to each operation type a learnable predictive component \(g_{\theta_j}\). The only learning signal is the output of the terminal measurement-instrument node — intermediate traces are used neither for training nor for evaluation. → Method details
  • Handle the whole protocol, not point queries. We learn the experimental configuration \(x\) and the terminal measurement \(y\) as a single structured response.
  • Reuse knowledge at the operation level. Even when the same operation type appears in different protocols, positions, or numbers of occurrences, it shares an identical predictive component.
  • Transfer zero-shot to unseen protocols. When identifiability holds, the source observation error controls the target error (knowledge-transfer upper bound).
  • Correct in closed loop via active learning. We select the next experiment \((p,x)\) from the predictive uncertainty, add terminal measurements, and correct the residual.
  • A surrogate-model foundation for autonomous experimentation. Structured surrogate modeling positioned between a full mechanistic model and a single black box.

Experimental claims

The experiments decompose into two claims

We measure ongoing surrogate performance with the macro NRMSE curve against the cumulative acquisition cost \(b\) of target labels. \(b=0\) is forward transfer; \(b>0\) is active adaptation. Clicking each card navigates to the experiment page supporting that claim (Goal, Setup, Result, Discussion). All experiments are terminal-only (observing only a single terminal scalar \(y\) per protocol execution), and only the intermediate-observation ablation (1-C of Claim 1) introduces observers in stages during training.

1
Transfer (b=0): when the conditions hold, OFML aids transfer

Treating a protocol as a composition of shared operation modules, when the identifiability of the reused operations and correct model specification both hold, it transfers zero-shot to an unseen target even under terminal-only. When they break, it fails, and the condition can be recovered with intermediate observations during training.

① Common posterior-moment convergence (Proposition)

By Banach-valued Lévy upward convergence, the posterior mean and second moment converge uniformly, \(\mu_n\to\mu_\infty\), \(v_n\to v_\infty\) (in \(C(\mathcal{X})\)). It does not rely on Gaussian-process updates.

② Supermartingale of the residual uncertainty (Lemma)

\(H_n=\int v_n\,d\lambda\) is a nonnegative supermartingale, and the one-step expected reduction at the selected point coincides with the acquisition function, \(D_n=\Delta^{\mathrm{IVR}}_n(X_{n+1})\), hence \(\sup_x\Delta^{\mathrm{IVR}}_n(x)\to0\).

③ Noisy IVR/SUR consistency (main theorem)

With the linear-predictor lower bound plus the small-ball mass of a full-support measure, \(\left\lVert v_n\right\rVert_\infty\to0\), hence \(G=\mu_\infty\) and \(\left\lVert\mu_n-G\right\rVert_\infty\to0\) (even under fixed noise, the latent-function variance vanishes everywhere).

④ OFML target active correction (Theorem)
